# 1.8 expansion and hardening — decision log

Tagged **v1.8.0**. Coverage stays at the 1.7 gate of 82. The limits below
are still true.

## What landed

- `fsio.append_jsonl` with fsync. Manifest, SR screening, RAG ledger, mirror
  index append, and search-watch inbox use it. Torn last lines are skipped.
  GUI command records and snowball `write_report.json` use atomic replace.
- `paperful/http.py`: request hook rejects non-public URL literals; 401/403
  are not retried. `make_client` uses it with `retries=0` so `fetch_pdf`
  keeps its own loop. Local SearXNG uses `guard=False`.
- `paperful/log.py` redacts bearer tokens. Global `-v`.
- `paperful/cli_bind.py` holds Typer signatures. `cli.py` is the app tree
  (about 510 lines).
- SR: protocol exclude list, off-list exclude fails, reason histogram,
  identification link to an existing snowball or search run, CSV/RIS
  export and dry-run import, PRISMA JSON and SVG, Advanced `/review`
  (no nav item).
- Grey: `host_blocked`, `html_not_pdf` (still retryable), `engine_suspended`,
  `search watch due`, doctor playbook-gap row.
- `scripts/bench_synthetic.py` times a record walk beside the mirror scan.
  `over_budget` fails above 10%. It is not wired as a PR gate.
- `tests/test_write_text_allowlist.py` freezes modules that still call
  `write_text`.

## What this wave does not claim

- Coverage 85. The omit list for live-browser and UI job modules is unchanged,
  so the gate stays 82.
- Every `httpx.Client(` site. OpenAlex, Mendeley, GROBID, Twenty, and several
  command modules still construct their own client.
- A 10k performance budget in CI. Run
  `uv run python scripts/bench_synthetic.py --sizes 1000,10000` and compare
  by eye, or with `over_budget`, before calling a slowdown a regression.
- Publish attestations. The Rekor workaround stays.
- Waiting on coverage 85 before the tag. `v1.8.0` was cut with the gate
  still at 82. The nightly 10k budget is still not a CI job.
- SR queue file (`queue.jsonl`), second-reviewer agreement, and dogfood of
  `/review` on a real protocol. Those stay the next SR steps in
  `docs/ROADMAP.md`.
