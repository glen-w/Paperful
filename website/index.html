On your machine

There is no Paperful account. The workbench binds to this computer. Downloads, notes, peer-review packs, and the folder copy stay here. Zotero remains the catalogue. Optional AI uses Ollama locally, or an API you chose, and stays off until you turn it on. You copy the folder yourself.

Tool catalog

Default nav: Wanted, Discover, Ask, Library, Activity, and System. ⚙️ is Advanced. 🤖 is optional AI (off until you enable it).

Writing help

Tool What it does Guide
Peer review ⚙️ A draft you already wrote: structure and citations always; unquoted overlap vs held PDFs (quote/cite/review); optional academic discourse; optional claim locators guide
Suggest edits ⚙️ Apply a peer-review pack as locatable edits / tracked changes; overlap comments name a held item (no cite insert); strip hidden trackers on the copy; never overwrites the source guide
Stuff ⚙️ Extra library cites per sentence or outline section (needs the index; no chat model) guide

A week with your library

  1. Grow on Discover — a topic, people you follow, or a watch you run.
  2. On Wanted, preview what’s missing, then Grab. Files land on this computer and attach on Zotero 10 or newer.
  3. Ask the PDFs you already hold.
  4. Writing help on a draft you wrote: peer review and suggest edits against papers in the library.

Install

Docker Compose, Zotero open on the host, workbench at http://127.0.0.1:8765. 

git clone --branch v1.9.10 https://github.com/glen-w/Paperful.git
cd Paperful
cp .env.example .env
mkdir -p ../paperful-data ../paperful-out
cp config.minimal.toml ../paperful-data/config.toml   # set email
docker compose build
docker compose run --rm paperful doctor
docker compose up

Or without Docker (PyPI; campus / HTML PDF needs "paperful[serve,browser]"): 

uv tool install "paperful[serve]"     # or: pipx install "paperful[serve]"
mkdir my-paperful && cd my-paperful
printf 'email = "you@university.edu"\n' > config.toml
paperful doctor
paperful serve                        # http://127.0.0.1:8765

Omit --branch v1.9.10 to track latest main. Docker · Zotero · First 10 minutes
