paperful

Clean the library. Find the PDFs. Keep a mirror.

paperful helps you fill missing PDFs in Zotero, tidy the records you already have, and keep a folder copy you can back up or hand to another tool. Open access first; campus access when you have it. Everything runs on your machine.

Built for Zotero. Mendeley and EndNote welcome testers. Version 0.9.0.

How it helps

Grow the library from a search or seed papers. Fill PDFs for items you already keep. Each attachment keeps a clear source line — for example, “Free copy from Unpaywall.”

1. Install once, stay local

Clone the repo and build with Docker Compose. Zotero stays on your computer; paperful talks to it through the local API. Zotero 10+ attaches PDFs for you; 7–9 still save them to disk.

2. Preview, then fill

docker compose run --rm paperful doctor
docker compose run --rm paperful run -C interesting --preset oa --dry-run

Start with a dry-run so you see what would change. Use --preset oa for open access. With campus EZProxy, switch to --preset eoi after a one-time login on the host.

3. You stay in control

Writes land on disk first; you choose when to apply them. Scholar, Sci-Hub, and the local model stay off until you turn them on. Not every paywalled paper will come back — and that is by design.

What you can do

  • Tidy a collection — fix identifiers, review duplicates, summarise if you want
  • Find PDFs through open access, campus access, and playbooks you write
  • Grow the library from a keyword, DOI, or ORCID
  • Snapshot everything to a folder and restore only what is missing
  • Export the mirror as RIS, BibTeX, or EndNote XML
  • Use campus EZProxy without storing your password
  • Leave Scholar, Sci-Hub, and AI summarisation off until you need them

Your machine, your files

paperful is a local tool. It reads your catalogue through an adapter — Zotero’s local API is the path that is well tested. Session cookies stay under state/sessions/. Your mirror lives in out/, ready to copy wherever you like.

From install to a filled collection

  1. Copy config.minimal.toml, add your email, and run paperful doctor.
  2. List collections and see which ones still need PDFs: paperful collections.
  3. Dry-run a collection, then fetch and attach.
  4. Optionally log in to EZProxy or Scholar before a larger run.

Install

Build on your machine — there is no app store package and no published Docker image. Keep Zotero on the host with the local API enabled. 

git clone https://github.com/glen-w/Paperful.git
cd Paperful
cp .env.example .env
cp config.minimal.toml config.toml
docker compose build
docker compose run --rm paperful doctor
docker compose run --rm paperful run --collection interesting --preset oa --dry-run
# campus: --preset eoi, after uv run paperful session login ezproxy on the host

Version 0.9 builds from a tagged clone. Full setup: Docker · Zotero · documentation. Headed login uses uv on the host.
