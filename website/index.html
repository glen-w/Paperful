How a fill works

  1. Pick a collection on Library, then open Wanted.
  2. Preview the fetch. Open-access indexes first; campus EZProxy if you have it. Not every paywalled paper comes back.
  3. Grab writes PDFs under out/ on this machine. Zotero is unchanged until you Attach.
  4. Attach copies you trust into Zotero. Tidy duplicates and identifiers on Repair when the collection is messy.

Install

Clone and build. No app store, no published image. Zotero stays on the host with the local API enabled. 

git clone https://github.com/glen-w/Paperful.git
cd Paperful
cp .env.example .env
cp config.minimal.toml config.toml   # set email
docker compose build
docker compose run --rm paperful doctor
docker compose up                    # http://127.0.0.1:8765
  • Edit .env and a real email in config — renaming the example files is not enough.
  • Minimal config is open access only. Campus EZProxy: EZProxy.
  • .env.example builds the heavy image. CI uses light. Docker.
