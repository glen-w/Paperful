# Assessments

This directory contains dated critical reviews of Paperful. These are **not shipping documentation** — they are operator-facing product assessments for the maintainer to act on.

## Purpose

Assessments capture honest, blunt product evaluations:
- Usability friction and onboarding gaps
- Documentation inconsistencies and missing guides  
- Feature coverage vs promises
- Prioritized findings for the maintainer

## Format

Each assessment is dated (`YYYY-MM-DD-brief-description.md`) and includes:
- Executive verdict (what works, what's broken)
- Evidence-based findings (cited from repo paths)
- Severity rankings (P0/P1/P2)
- Recommended next actions

## Not Included

- Marketing copy or feature announcements
- User-facing tutorials (those belong in `docs/`)
- Release notes (see `CHANGELOG.md`)
