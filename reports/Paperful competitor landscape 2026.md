# Fix three cells, then expand peers

As of **2026-11-26**, Paperful’s comparison docs are **mostly current on major named peers** (Edison, Elicit, Valency, OpenResearch, PaperOrchestra, PaperGuard, SummarizePaper, zotero-agent, SR tools, writers) but **stale in three ways that matter for maintainers**. First, two **internal contradictions / wrong cells** should ship before any peer expansion: Paperful attachment repair is **Partial** in `comparison.md` and **No** in `comparison-reference.md`, and the Zotero-version table still bundles StorScan/Attanger/ZotMeta/zotodata as “7–9” against current READMEs. Second, product copy drifted under Consensus (**Deep Review / Literature Review Skill** writes structured lit-review reports) while the stage matrix still says Write MS = **No** (“will not write your literature review”), and SciSpace still links via `typeset.io` instead of `scispace.com`. Third, **social and GitHub discovery outpaced the MCP and in-Zotero fetch rows**: the docs name three low-adoption MCP forks while omitting **`54yyyu/zotero-mcp` (~6,077★)**, and they miss 2025–2026 Zotero PDF/RAG peers (**ZotFetch**, **Littview OpenAlex PDF**, **PapersGPT**, **SeerAI**, **ZotSeek**) plus hosted discover peers (**Ai2 Asta**, **Paperguide**, **Anara**, **Logically**). No listed major product appears shut down; Paperful’s scarce empty cell—campus-proxy / grey fetch plus a **disk mirror + restore ledger**—still has **no first-class OSS peer**. This report is for deciding what to change in `docs/comparison.md` and `docs/comparison-reference.md`; it does not edit those files.

## Three wrong cells beat every missing peer

The accuracy pass against public docs on **2026-11-26** found the Short answer routing table still largely matches vendor positioning for Paperful’s own jobs and for Edison, Elicit (~**138M** papers), Valency Bond, OpenResearch, PaperOrchestra, PaperGuard (~**41** detectors on PyPI), SummarizePaper, and the Zotero helpers already named ([Elicit paper sources](https://support.elicit.com/en/articles/14758040-elicit-s-source-for-papers); [Edison docs](https://docs.edisonscientific.com/); [Valency docs](https://docs.valency.io/); [paperguard on PyPI](https://pypi.org/project/paperguard/)). The **executive staleness grade is “correct skeleton, dirty cells”**: keep the factory-stage framing from the October 2026 research, fix contradictions first, then widen the peer list where social mindshare and GitHub activity already moved.

**Critical accuracy fixes.** Align **Paperful “Attachment / disk repair”** in `comparison-reference.md` from **No** to **Partial** so it matches `comparison.md`’s “broken link / file layout repair = Partial (`attachments`; report by default, surgery with `--apply`)”; leaving both tables as-is teaches maintainers and readers opposite facts about the same product. **Important but non-blocking stale claims.** Prefer **`https://scispace.com/`** over `https://www.typeset.io/` in Short answer and Hosted literature links (redirect still works; brand is SciSpace) ([Typeset → SciSpace](https://scispace.com/guides/typeset-evolving-into-scispace)). ## Social and GitHub pressure lands on fetch and MCP, not on the mirror

Community recommendations in 2025–2026 still cluster around Elicit / Consensus / SciSpace / Undermind / NotebookLM for hosted lit work, with **no viral “Zotero killer”** and no abandonment signal for those incumbents ([r/AIToolsAndTips 2026 lit-review thread](https://www.reddit.com/r/AIToolsAndTips/comments/1tje38x/best_ai_tools_for_literature_reviews_in_2026_i/); [Undermind status](https://verdict.tools/status/undermind)). Viral energy shifted to **MCP bridges into Zotero** and **in-app AI**. Parallel pressure on Paperful’s **Ask** niche comes from **PapersGPT** (~2,716★), **SeerAI** (~97★), **ZotSeek** (~245★), and commercial **DeepTutor** (Zotero fork + Graph RAG; HN + r/zotero) ([papersgpt-for-zotero](https://github.com/papersgpt/papersgpt-for-zotero); [dralkh/seerai](https://github.com/dralkh/seerai); [introfini/ZotSeek](https://github.com/introfini/ZotSeek); [DeepTutorZotero](https://github.com/KnoWhiz/DeepTutorZotero)).

Hosted side, **Ai2 Asta** (108M+ abstracts / 12M+ full text), **Paperguide**, **Anara**, and **Logically** (ex-Afforai, Deep Research Nov 2026) are the highest-signal comparison gaps; Litmaps owns ResearchRabbit (two products, one company) and should appear as a citation-map cluster rather than independent “competitors” to Paperful Wanted ([asta.allen.ai](https://asta.allen.ai/); [Logically rebrand](https://logically.app/blog/afforai-is-now-logically/); [Litmaps vs ResearchRabbit](https://paperguide.ai/blog/litmaps-vs-researchrabbit/)). LibKey vs “publisher full text used for analysis” on Consensus is a copy-judgment footnote, not fully resolved for the Get PDF column. Undermind official Zotero docs were not deep-fetched (third-party matrices say No). MirrorThink → Vicena was not confirmed by a primary fetch.

**Runtime and private communities.** Plugin Zotero 10.x claims come from README/manifest/Atlas, not re-run install tests. Discord/Slack lab communities were not indexed. DeepTutor’s “4,000+ users” claim is vendor Reddit only. Star counts are same-day GitHub API snapshots (±daily noise). Some Reddit “best tools 2026” threads and SciSpace-vs-Elicit pages are SEO-flavored and were down-weighted relative to librarian reviews, Show HN + repo activity, and multi-comment academic threads.

**Census honesty.** “No project matches Paperful’s collection-folder mirror + restore ledger” is inferred from targeted GitHub/README sampling, not a formal census of every Zotero plugin. Missing-peers lists for lit-MCP beyond Valency/Elicit/OpenAlex official are **not claimed complete**.

## Conclusion

The comparison table’s **architecture is still right**: route hosted discover and AI-scientist jobs out, own Wanted + restore, keep Sci-Hub brief. What aged is **cell honesty** (attachments, Zotero versions, Consensus Write MS, SciSpace URL, SummarizePaper upload wording) and **peer naming** where the community already consolidated on **54yyyu MCP** and a new wave of **in-Zotero fetch/RAG** tools while Paperful stayed silent. Ship the three critical cell fixes immediately; in the same docs PR, lead the MCP row with 54yyyu, name ZotFetch/Littview beside zotodata, and add Asta/Paperguide to hosted discover so maintainers stop answering “why isn’t X in the table?” from memory. Leave grey-zone Sci-PDF/PDFerret and enterprise Iris.ai out of the customer Yes/No grid; keep pointing Kosmos-class loops at Edison. The differentiator that still survives this landscape check is not chat or semantic search—it is the **disk-first restore ledger with campus and grey fetch**, which social threads barely discuss and GitHub still barely clones.
